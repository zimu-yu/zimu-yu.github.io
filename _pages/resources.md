A growing collection of books, documentation, and tools related to my research. The links point to official project pages or learning materials.

## Machine learning

- [Dive into Deep Learning](https://d2l.ai/) — an interactive introduction to deep learning, combining mathematical explanations and code.
- [Probabilistic Machine Learning](https://probml.github.io/pml-book/) — a reference for probabilistic modeling and machine learning.
- [PyTorch documentation](https://pytorch.org/docs/stable/index.html) — reference documentation for models, tensors, and training workflows.

## Protein modeling & engineering

- [ProteinGym](https://proteingym.org/) — resources for evaluating protein fitness prediction.
- [ESM](https://github.com/facebookresearch/esm) — protein language models and associated tools.
- [ProteinMPNN](https://github.com/dauparas/ProteinMPNN) — protein sequence design conditioned on structure.
- [Rosetta](https://www.rosettacommons.org/) — software and resources for biomolecular modeling.

## Single-cell & computational biology

- [Scanpy](https://scanpy.readthedocs.io/) — tools for analyzing single-cell gene expression data.
- [scverse](https://scverse.org/) — an ecosystem of tools for single-cell analysis.
- [Biopython](https://biopython.org/) — Python tools for biological computation.

## Mathematics & statistics

Useful foundations for the topics above include linear algebra, probability, statistical inference, and optimization. I will add specific reading notes as this collection grows.

## Research software

- [Python documentation](https://docs.python.org/3/) — language and standard-library reference.
- [R Project](https://www.r-project.org/) — statistical computing and graphics.
- [Git documentation](https://git-scm.com/doc) — version control and collaborative development.
